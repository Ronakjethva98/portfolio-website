# Premium Portfolio Website

A modern, responsive, and high-performance portfolio website built with vanilla HTML, CSS, and JavaScript.

## ✨ Features
- **Glassmorphism Design**: Modern aesthetic with blurred backgrounds and sleek borders.
- **Scroll Animations**: Uses AOS (Animate On Scroll) for smooth reveal effects.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.
- **Modern Typography**: Integrated with Google Fonts (Outfit & Inter).
- **Interactive Elements**: Smooth scrolling, hover effects, and contact form handling.

## 🚀 How to Deploy on GitHub Pages
1. **Create a Repository**: Go to GitHub and create a new repository named `my-portfolio`.
2. **Upload Files**: Upload all the files from this folder (`index.html`, `style.css`, `script.js`) to the repository.
3. **Enable GitHub Pages**:
   - Go to your repository **Settings**.
   - Click on **Pages** in the left sidebar.
   - Under "Build and deployment", select **Deploy from a branch**.
   - Choose the `main` branch and `/ (root)` folder, then click **Save**.
4. **Share Your Link**: After a minute, GitHub will provide a link like `https://your-username.github.io/my-portfolio/`.
